# TFC

A terminal UI for managing and studying flashcard sets.

## About

My motivations for working on this project were:
- To gain experience using go
- Create a terminal UI
- Hopefully study notes with my very own flashcard app instead of using something like Quizlet

After using [lazygit](https://github.com/jesseduffield/lazygit) for the first time, I found that I REALLY like terminal UIs
